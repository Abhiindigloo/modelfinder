Keep your data close.

Supported: 1.3.x (latest) · Report privately via GitHub

Model Finder is designed so that the safe thing is the default: a local MCP server with no dependencies, read-only tools that never touch the network, and a single opt-in tool that cannot spend money without your explicit confirmation.

Report a vulnerability

Please do not open a public issue for a security problem. Use GitHub private vulnerability reporting: the repository's Security tab → Report a vulnerability. Include the version, the component, steps to reproduce and expected impact. Use placeholders, never real API keys or personal data.

Best effort: acknowledgement within 5 business days, initial assessment within 10, and coordinated disclosure within 90 days. Good-faith research on your own installations is welcome under safe harbour.

MCP server

  • Local stdio only. It writes no files and never logs tool arguments.
  • Ten tools are read-only and offline: they open no network connections, read no API keys and declare readOnlyHint: true and openWorldHint: false.
  • modelfinder_run_eval is opt-in and declares openWorldHint: true. It calls nothing unless confirm is true, runs only the models you list, refuses runs over max_calls (default 50, hard limit 200), and connects only to those providers' endpoints, plus LiteLLM's public price file when you ask for it.
  • Repository tools stay inside the workspace, refuse the filesystem root and home directory, do not follow symlinks, skip secret-like files and cap files at 1 MB and 5,000 files.

Keys and transport

  • Keys are read only from environment variables named in configs. Configs that embed keys, tokens or secrets are rejected. Keys are never printed or written to disk, and are scrubbed from provider errors.
  • HTTPS is required; plain HTTP is allowed only for loopback hosts (local runtimes). Redirects are refused, so credentials are never forwarded to another host.
  • Response bodies, inputs and pattern lengths are capped.

Supply chain

  • Python standard library only: the PyPI package has no dependencies.
  • GitHub Actions are pinned to commit SHAs. Releases publish to PyPI with trusted publishing (no stored token) and to the MCP Registry under the verified co.indigloo namespace.
  • Skills are plain Markdown with no hidden, encoded or remotely fetched instructions.

This website

A static site with a strict Content Security Policy: scripts, styles, fonts, images and video load only from this origin, with no inline script, no third-party code and no forms. It has no accounts, cookies or storage.
