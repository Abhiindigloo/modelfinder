Simple by design.

Effective 19 October 2026 · Applies to Model Finder 1.3.x and this website

  • Model Finder runs on your own computer. Indigloo does not receive, store or see any data you use with it.
  • No accounts, no sign-in, no telemetry, no analytics, no cookies, no advertising.
  • The local MCP server needs no API keys, writes no files and never logs what you send it. Ten of its eleven tools make no network connections.
  • The one exception is the opt-in modelfinder_run_eval tool. Only when it is called with confirm: true does it send your eval examples, and only to the model providers you list, using your API keys from environment variables.

Model Finder is published by Indigloo Softwares Private Limited ("Indigloo", "we"), a company incorporated in India. This page summarises the full privacy policy in the repository, which takes precedence if the two differ.

Data minimisation

  • Repository tools read only inside your workspace and refuse a filesystem root or home folder.
  • They skip secret-like files (.env, keys, certificates, credentials and tokens), dependency folders and symbolic links.
  • modelfinder_audit_models returns model IDs, file names and line numbers, never line content.
  • Drafted eval examples that contain detected personal data or secrets are dropped. The sensitive-data scan reports categories and counts, never values.
  • Eval runs are blocked when examples contain detected personal data unless you explicitly allow it. API keys are never sent as content, printed or written to disk.

This website

This is a static site. It sets no cookies, runs no analytics or third-party scripts, and loads every font, image and video from its own origin. Its script only handles the menu, animations, tabs and copy buttons; it makes no network requests and stores nothing. Our hosting provider may process standard request logs (such as IP address and user agent) to serve and protect the site.

What Indigloo collects

Through the software: nothing. Indigloo runs no server, API or hosted service for Model Finder. If you open an issue, discussion or pull request on GitHub, we receive what you post and your GitHub username, and use it only to respond and improve the software. Package registries and marketplaces may record downloads under their own policies. We do not sell or share personal data, and we do not use it for advertising or AI training.

Third parties you choose

When you configure a model provider, your prompts go to that provider using your account, and its terms apply, including retention and training rules. Check them before sending real data. Your organisation decides what is sent and why, and is responsible for its legal basis under laws such as India's Digital Personal Data Protection Act 2023.

Contact

Open an issue on GitHub asking for a private channel, without including personal details. For security matters use private vulnerability reporting; see Security.
